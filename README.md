# Go Low-Level Design Concepts

This repository implements core object-oriented design patterns and low-level design concepts in Go, demonstrating how to achieve OOP principles in a statically-typed language.

## 🎯 Purpose

The goal of this project is to showcase how fundamental software engineering concepts can be implemented in Go, even though it's not a class-based object-oriented language. Each concept demonstrates practical applications and best practices.

## 📁 Current Implementations

### Core OOP Concepts

- **Abstraction**: Demonstrates hiding implementation details behind clean interfaces
- **Encapsulation**: Shows data protection through controlled access patterns
- **Inheritance**: Achieves "inheritance" via Go's composition model
- **Polymorphism**: Illustrates different implementations satisfying the same interface

## 🚀 How to Use

Each concept is self-contained in its own directory with:
- Clear implementation examples
- Comprehensive comments explaining design decisions
- Practical use cases

```bash
# Clone the repository
git clone https://github.com/improver2108/golld.git

# Navigate to a specific concept
cd golld/abstraction

# Run the example
go run main/main.go
```

## 📝 Code Structure

Each directory follows this pattern:
- `package/` - Contains the implementation code
- `main/` - Contains usage examples and demonstration code
- Clear separation of concerns
- Well-commented code explaining design principles
